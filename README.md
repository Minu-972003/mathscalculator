# Simple Calculator in C

## Description

This is a simple calculator program written in C. It allows users to perform basic arithmetic operations:

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)

The program also checks for division by zero and displays an error message if the user attempts to divide by zero.

## Features

* User-friendly input
* Supports floating-point numbers
* Handles invalid operators
* Prevents division by zero errors

## How to Compile

Using GCC:

```bash
gcc calculator.c -o calculator
```

## How to Run

```bash
./calculator
```

On Windows:

```bash
calculator.exe
```

## Example

```
Enter first number: 10
Enter an operator (+, -, *, /): *
Enter second number: 5

Result = 50.00
```
